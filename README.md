# Data-Visualization-Projects
Description: This repository showcases a collection of data visualization projects demonstrating my skills in data analysis, dashboard creation, and translating complex datasets into actionable insights. Most datasets are publicly available from Kaggle (except my personal passion project, which uses self-collected data on reading and video game hours). Projects highlight my ability to clean, analyze, and visually present data using tools such as Power BI, Tableau, and Excel.

## Projects

### Diabetes Dashboard

Dataset: Publicly available from Kaggle.

Description: Visualizes diabetes-related health indicators and trends across populations.

Skills/Tools: Tableau, Excel, data cleaning, descriptive statistics, and trend analysis.

Key Takeaways: Designed to help public health practitioners identify high-risk populations and monitor interventions.

### Video Game Sales Dashboard

Dataset: Publicly available from Kaggle.

Description: Tracks and visualizes video game sales data by platform, genre, and region.

Skills/Tools: Power BI, data aggregation, interactive dashboards.

Key Takeaways: Demonstrates ability to analyze commercial datasets and present insights clearly.

### Fitbit Activity Dashboard

Dataset: Publicly available from Kaggle.

Description: Tracks activity data including steps, calories, and sleep patterns over time.

Skills/Tools: Power BI, exploratory data analysis.

Key Takeaways: Highlights processing wearable device data and visualizingpersonal health trends.
